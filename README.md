# Сервис планирования использования помещений

Учебный сквозной проект по дисциплине «Технологии разработки приложений на
базе фреймворков».

## Предметная область

Сервис помогает учитывать помещения, мероприятия, пользователей и расписание.
В ПР1 реализован базовый сценарий: программа проверяет вместимость и
доступность аудитории, рассчитывает продолжительность мероприятия и сообщает,
можно ли добавить его в расписание.

## Запуск

```bash
python3 main.py
```
