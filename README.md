# Сервис планирования использования помещений

Учебное консольное приложение для ведения перечня помещений и расписания
мероприятий. Основные сущности проекта: помещение, мероприятие, пользователь и
расписание.

## Возможности ПР2

- просмотр, поиск, фильтрация и сортировка помещений;
- подбор помещения по числу участников;
- добавление мероприятия с проверкой вместимости и занятости;
- удаление мероприятия и просмотр расписания;
- хранение помещений и расписания в JSON;
- обработка ошибок ввода, файлов и конфликтов времени.

## Структура

- `main.py` — консольное меню;
- `rooms.py` — функции работы с помещениями;
- `schedule.py` — функции работы с мероприятиями и расписанием;
- `storage.py` — чтение и запись JSON;
- `utils.py` — проверка числового ввода;
- `data/` — данные помещений и расписания;
- `tests/` — автоматизированные тесты.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

## Проверка

pytest -v
