# Система бронирования помещений

## Назначение

Консольное приложение помогает проверить возможность бронирования учебного
помещения на выбранную дату и предварительно рассчитать стоимость аренды.

## Целевая аудитория

Приложение предназначено для студентов, преподавателей, администраторов
образовательных организаций и других пользователей, которым требуется помещение
для занятия или мероприятия.

## Предметная область

Предметная область охватывает помещения, пользователей и бронирования. Для
помещения учитываются название, вместимость, доступность и стоимость аренды.
Бронирование связывает пользователя с помещением и датой мероприятия.

## Основные сущности

- помещение;
- пользователь;
- бронирование.

## Основные функции

- проверка соответствия вместимости помещения числу участников;
- определение статуса доступности помещения;
- расчёт предварительной стоимости аренды;
- вывод итогового решения о возможности бронирования.

## Реализовано в ПР1

Реализован начальный сценарий проверки бронирования. Программа получает число
участников и продолжительность мероприятия, проверяет вместимость и доступность
помещения, рассчитывает стоимость и выводит результат.

## Запуск

Требуется Python 3.10 или новее.

```bash
python main.py
```

## План развития

На следующих этапах планируется:

- добавить коллекции помещений, пользователей и бронирований;
- разделить программу на модули;
- реализовать загрузку и сохранение данных в JSON;
- добавить обработку исключений и автоматизированные тесты;
- представить сущности предметной области классами;
- разработать веб-приложение на Django;
- подключить базу данных;
- реализовать регистрацию и аутентификацию пользователей;
- разработать REST API;
- контейнеризировать приложение;
- настроить CI/CD.
