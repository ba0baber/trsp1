# Сервис планирования использования помещений

Учебное консольное приложение для ведения перечня помещений и расписания
мероприятий. Основные сущности проекта: помещение, мероприятие, пользователь и
расписание.

## Возможности

- просмотр, поиск, фильтрация и сортировка помещений;
- подбор помещения по числу участников;
- добавление мероприятия с проверкой вместимости и занятости;
- удаление мероприятия и просмотр расписания;
- хранение помещений и расписания в JSON;
- обработка ошибок ввода, файлов и конфликтов времени.

## Объектная модель ПР3

- `Room` хранит характеристики помещения и проверяет вместимость;
- `User` представляет организатора, а свойство `email` обеспечивает
  инкапсуляцию и проверку адреса;
- `Event` связывает пользователя с помещением, хранит время мероприятия,
  вычисляет продолжительность и проверяет пересечения;
- `Schedule` содержит объекты `Event`, добавляет и удаляет мероприятия,
  предотвращает двойное бронирование помещения.

У классов реализованы конструкторы, методы, аннотации типов и `__str__`.
Загрузка JSON создаёт связанные объекты, а сохранение преобразует их обратно в
JSON-словари.

## Структура

- `main.py` — консольное меню и взаимодействие объектов;
- `models.py` — классы `Room`, `User` и `Event`;
- `rooms.py` — операции с коллекцией объектов `Room`;
- `schedule.py` — класс `Schedule`;
- `storage.py` — преобразование объектов и работа с JSON;
- `utils.py` — проверка числового ввода;
- `data/` — данные помещений и расписания;
- `tests/` — автоматизированные тесты.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```
