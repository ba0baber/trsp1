# Система учёта коллекции скинов Counter-Strike

## Назначение

Консольное приложение помогает вести личную коллекцию виртуальных предметов
Counter-Strike. На первом этапе оно проверяет возможность покупки выбранного
скина с учётом его доступности, износа, цены и баланса пользователя.

## Целевая аудитория

Приложение предназначено для игроков Counter-Strike, которые хотят учитывать
состав и стоимость своей коллекции скинов.

## Предметная область

Предметная область включает пользователей, игровые скины, коллекции и операции
с предметами. У скина есть название, цена, износ, состояние и доступность.
Пользователь хранит скины в коллекции и может планировать их покупку или обмен.

## Основные сущности

- пользователь;
- скин;
- коллекция;
- сделка.

## Основные функции

- определение состояния скина по значению износа;
- проверка допустимого диапазона износа;
- расчёт остатка средств после покупки;
- проверка возможности добавления скина в коллекцию;
- просмотр и оценка стоимости коллекции на следующих этапах.

## Реализовано в ПР1

Реализован начальный сценарий проверки покупки одного скина. Программа получает
значение износа, определяет состояние экземпляра, проверяет допустимый диапазон,
сравнивает цену с балансом пользователя и выводит итоговое решение.

Приложение не подключается к Steam и не выполняет реальные платежи или сделки.
Все данные на текущем этапе являются учебными.

## Запуск

Требуется Python 3.10 или новее.

```bash
python main.py
```

## План развития

На следующих этапах планируется:

- добавить коллекции скинов и пользователей;
- реализовать поиск, фильтрацию и оценку коллекции;
- разделить программу на модули;
- добавить загрузку и сохранение данных в JSON;
- реализовать обработку исключений и автоматизированные тесты;
- представить сущности предметной области классами;
- разработать веб-приложение на Django;
- подключить базу данных;
- реализовать регистрацию и аутентификацию пользователей;
- разработать REST API;
- контейнеризировать приложение;
- настроить CI/CD.
