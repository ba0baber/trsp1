# Система учёта коллекции скинов Counter-Strike

Учебное консольное приложение для ведения коллекции виртуальных предметов.
Программа не подключается к Steam и не выполняет реальные платежи или сделки.

## Возможности

- просмотр каталога скинов;
- поиск по названию и оружию;
- фильтрация доступных скинов по цене;
- сортировка каталога по стоимости;
- покупка с проверкой доступности и баланса;
- удаление предмета из коллекции;
- подсчёт стоимости коллекции;
- сохранение каталога и коллекции в JSON.

## Развитие проекта

В ПР1 был реализован сценарий проверки одного скина: определение состояния по
износу, проверка доступности и расчёт остатка средств. В ПР2 этот сценарий
сохранён и расширен для работы с каталогом и коллекцией. Данные представлены
списками и словарями, а логика распределена по функциям и модулям. В ПР3
основные сущности преобразованы в классы и взаимодействуют как объекты.

## Объектная модель ПР3

- `Skin` хранит данные скина, вычисляет состояние, управляет доступностью и
  преобразуется в JSON-словарь;
- `User` хранит имя и инкапсулированный баланс, а метод `pay()` выполняет
  проверяемое списание;
- `CollectionItem` описывает связь владельца с купленным скином;
- `Collection` содержит объекты `CollectionItem` и реализует покупку, удаление,
  поиск предметов владельца и подсчёт общей стоимости.

Методы `__str__` дают удобное строковое представление объектов. Методы
`from_dict()` и `to_dict()` преобразуют JSON в объекты и объекты обратно в JSON.

## Структура

- `main.py` — консольное меню и точка запуска;
- `models.py` — классы `Skin`, `User` и `CollectionItem`;
- `skins.py` — поиск, фильтрация, сортировка и генератор объектов `Skin`;
- `collection.py` — класс `Collection` и взаимодействие объектов;
- `storage.py` — преобразование объектов и чтение/запись JSON;
- `utils.py` — безопасный ввод чисел;
- `data/` — JSON-файлы каталога и коллекции;
- `tests/` — автоматизированные тесты;
- `requirements.txt` — инструменты разработки.

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для Windows команда активации:

```powershell
.venv\Scripts\activate
```

python main.py
