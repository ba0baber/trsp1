# Подготовка к защите ПР1

## Материалы Python

1. Основные типы данных: `int` хранит целые числа, `float` — вещественные,
   `str` — текст, `bool` — логические значения. Также используются коллекции и
   импортируемые типы, например `Decimal`.
2. `int` и `float` предназначены для чисел, `str` — для последовательности
   символов, `bool` принимает `True` или `False`.
3. Преобразование типов нужно, когда данные получены в одном виде, а обработать
   их требуется в другом. Например, `input()` возвращает строку, поэтому для
   вычислений применяется `float(input(...))`.
4. Строки можно объединять, повторять, сравнивать, индексировать, получать
   срезы и обрабатывать строковыми методами.
5. Операторы сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`.
6. `if` выполняет блок кода только при истинном условии.
7. `if` проверяет первое условие, `elif` — дополнительные условия, `else`
   выполняется, если предыдущие условия ложны.
8. Составные условия записываются с помощью `and`, `or` и `not`.
9. `and` требует истинности всех условий, `or` — хотя бы одного, `not`
   инвертирует логическое значение.
10. Модуль Python — файл с кодом, который можно подключить к другой программе.
11. `import` позволяет использовать функции, классы и значения другого модуля.
12. `import decimal` подключает модуль целиком, а `from decimal import Decimal`
    импортирует конкретный объект.

## Рабочее окружение

13. Виртуальное окружение изолирует зависимости одного проекта от других.
14. IDE — среда разработки с редактором, запуском, отладчиком и навигацией.
15. Git хранит историю изменений и позволяет возвращаться к версиям проекта.
16. Репозиторий — каталог проекта вместе с историей Git.
17. Commit — зафиксированный снимок изменений с сообщением.
18. `.gitignore` исключает временные файлы, окружение и настройки IDE.
19. `README.md` объясняет назначение, структуру, запуск и развитие проекта.
20. Отладка — поиск причины неправильной работы через наблюдение за выполнением.
21. Breakpoint — точка, в которой отладчик приостанавливает программу.
22. Пошаговое выполнение позволяет увидеть порядок команд и значения переменных.

## Индивидуальный проект

23. Приложение ведёт учебный учёт коллекции скинов Counter-Strike.
24. Пользователи — игроки, которым нужен каталог и оценка коллекции.
25. Основные сущности: пользователь, скин, коллекция и сделка.
26. Планируются поиск, фильтрация, добавление, удаление, оценка коллекции и
    хранение данных.
27. В ПР1 реализована проверка покупки одного скина с учётом износа, цены,
    доступности и баланса.
28. Использованы строки, числа, логические значения, `Decimal`, функции,
    преобразование типов, арифметика, условия и импорт.
29. После ООП появятся классы предметной области, после Django — модели базы
    данных, страницы, формы, пользователи и API.
30. Тема подходит для веб-приложения, потому что содержит связанные сущности,
    пользователей, операции CRUD, поиск, фильтрацию и хранение данных.

## Что показать в коде

- функции ПР1 сохранены в `skins.py` и `collection.py`;
- условия определения состояния находятся в `get_skin_condition()`;
- расчёт баланса находится в `calculate_balance_after_purchase()`;
- история этапов доступна через `git log --oneline`.
